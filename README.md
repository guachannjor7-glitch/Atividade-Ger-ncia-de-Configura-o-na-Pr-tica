# Atividade-Ger-ncia-de-Configura-o-na-Pr-tica
O sistema selecionado é o Sistema de Controle de Alunos, uma aplicação desktop básica desenvolvida para o contexto educativo. A finalidade do sistema é simplificar a administração do corpo estudantil, possibilitando o registro e o acesso ágil às informações dos alunos de uma instituição.
